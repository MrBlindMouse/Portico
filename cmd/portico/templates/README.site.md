# Portico SSH site

```bash
go run .
```

SSH (dev): `ssh -p 2222 -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null localhost`

Optional: `PORTICO_DATA`, `PORTICO_LOG_LEVEL=debug`
